# SleepFlow

Трекер і аналізатор сну у вигляді PWA. Усі дані зберігаються лише на пристрої (IndexedDB), без сервера і реєстрації.

## Команди

```bash
npm install
npm run dev       # дев-сервер (доступний у локальній мережі, --host)
npm run dev:https # те саме з самопідписаним HTTPS — для мікрофона й датчиків на телефоні
npm run build     # перевірка типів + продакшн-збірка в dist/
npm run preview   # перегляд зібраної версії (з service worker, офлайн)
npm test          # юніт-тести (Vitest)
npm run icons     # перегенерувати PNG-іконки в public/icons
```

## Структура

- `src/analysis/` — чисті функції: метрики ночі, Sleep Score, класифікація стадій, гіпнограма
- `src/tracking/` — нічна сесія: мікрофон (Web Audio), акселерометр, Wake Lock, детектор хропіння, агрегація в 30-секундні епохи
- `src/db/` — схема Dexie, репозиторій, експорт/імпорт JSON, генератор демо-даних
- `src/screens/`, `src/components/` — UI
- `src/i18n/uk.ts` — усі рядки інтерфейсу

## Розумний будильник

- Вікно [будильник − N хв, будильник]: будить на першій епосі «Неспання» або «Легкий сон» з наростанням руху,
  якщо людина вже спала й дані свіжі; інакше — рівно в час будильника (`src/alarm/smartAlarm.ts`).
- Мелодія синтезується Web Audio, гучність наростає 0→100% за 75 с, плюс вібрація (Android).
  Коли дзвонить, мікрофон вимикається (на iOS активний запис приглушує динамік).
- «Відкласти» — 9 хв, «Вимкнути» — зберігає ніч з моментом пробудження.
- Перевірка без очікування до ранку: `?debug=1` → у нічному режимі кнопки «Будильник через 30 с»,
  «Розумне вікно 2 хв», «Задзвонити зараз».

## Аналітика (`src/analysis/`)

- `debt.ts` — борг сну за 7 днів; `stats.ts` — ряди для тижня/місяця/року.
- `correlations.ts` — вплив тегів і похідних факторів (пізнє лягання, вихідні); висновок лише якщо ≥3 ночі з фактором і ≥3 без.
- `insights.ts` — 3–5 порад тижня за правилами; `idealBedtime.ts` — персональний час лягання після 14+ ночей.

## Тест на телефоні

1. Комп'ютер і телефон в одній Wi-Fi мережі. `npm run dev:https`, відкрийте на телефоні адресу `https://<IP-комп'ютера>:5173/?debug=1`
   і прийміть попередження про сертифікат.
2. «Почати сон» → дозвольте мікрофон (і рух на iOS). Перші 2 хв — калібрування фону.
3. `?debug=1` показує живі графіки: рівень звуку і фон, частки спектра (хропіння/мова), акселерометр, останні епохи.
4. Через ~10 хв утримуйте кнопку внизу 1.5 с — відкриється збережена ніч з гіпнограмою.

Сесії коротші за 2 хв не зберігаються. Засинання фіксується після 5 хв спокою, глибокий сон — після 10 хв поспіль.
